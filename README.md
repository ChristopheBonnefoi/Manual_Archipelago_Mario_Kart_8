# Archipelago Manual for Mario Kart 8 Deluxe

## Welcome!
Welcome to my Archipelago manual for Mario Kart 8 Deluxe on the Nintendo Switch. This setup is inspired by the work of RampantEpsilon and JokerFactor. My goal is to provide a comprehensive Archipelago experience with fun and challenging checks.

## Project Status
This project is currently in **beta**. I plan to add many more features in future updates, as outlined in the **Future Features** section below.

## Current Features
- **All Rainbow Roads Completed**  
  Finish every Rainbow Road track in the game, including all DLC courses. (If you don’t own the DLC, just complete the original game’s Rainbow Roads and mark the goal as complete.)

## General Information

### Goal Explanations

#### All Rainbow Roads Completed  
Complete every Rainbow Road track in the base game and any DLC. If you haven’t purchased the DLC, you can still validate the goal after finishing all Rainbow Roads from the original game.

#### Trophy Checks  
For bronze, silver, and gold trophy checks: earning the gold trophy on a cup automatically validates the silver and bronze requirements.

#### Track Unlocks  
Unlocking a track in Grand Prix or VS Race mode will validate it for both, so you don’t have to unlock the same course twice.
